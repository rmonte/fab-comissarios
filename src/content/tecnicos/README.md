# Dados Técnicos das Aeronaves

Esta pasta contém fichas técnicas por modelo de aeronave.

## Como adicionar uma nova ficha

Crie um arquivo `.md` com o seguinte frontmatter:

```markdown
---
title: Nome da Aeronave
slug: nome-da-aeronave
category: tecnico
tags: [tag1, tag2]
aircraft: [sigla-da-aeronave]
---
```
