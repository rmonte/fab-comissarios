## Mnemonicos Rapidos

| Sigla | Significado |
|---|---|
| **RTO** | Rejected Take Off — Abortiva de Decolagem |
| **TEST** | Briefing estruturado com os pilotos |
| **KLM+E** | Kits · Lanternas · Megafone · ELT |
| **A-F-A+A** | Abrigo · Fogo · Agua · Alimento |
| **ESAON** | Estacione · Sente-se · Alimente-se · Oriente-se · Navegue |
| **SAMPLE** | Sinais · Alergias · Medicamentos · Passado · Last meal · Eventos |
| **DFaFI** | Deformidades · Feridas · Fraturas · Inchaço |
| **CSM** | Circulação · Sensibilidade · Movimentacao |
| **RICE** | Rest · Ice · Compression · Elevation |
| **C-A-B** | Circulacao · Abertura de vias · Boca-a-boca (ordem da RCP) |
| **PS=PS=PS** | Patamar de Seguranca: manter sentados · PS + Primeiros Socorros · PS + Verificar sanitarios |
| **LRBL** | Local de menor risco para a bomba (posicao 4R-centro) |
| **PBE** | Protective Breathing Equipment |
| **WAP** | Patamar intermediario (Wide Area Patrol) |
| **ELT** | Emergency Locator Transmitter |
| **PED** | Dispositivo eletronico pessoal |

## Vozes de Comando Essenciais

| Situacao | Voz de Comando |
|---|---|
| Pre-impacto (piloto) | *"Tripulacao, preparar para o impacto"* |
| Pre-impacto (comissario) | **"IMPACTO, IMPACTO!"** |
| Evacuacao (comissario) | **"SOLTEM OS CINTOS! DEIXEM TUDO! SAIAM POR AQUI!"** |
| Emergencia nao preparada | **"ABAIXEM-SE, ABAIXEM-SE!"** |
| Amerrissagem — evacuacao | **"FORMEM DUAS FILAS! INFLEM OS COLETES E SAIAM!"** |
| Aterrissagem — evacuacao | **"FORMEM DUAS FILAS! PULEM, PULEM!"** |
| Descida rapida (piloto) | *"Atencao, descida rapida, permanecam sentados, remain seated"* |
| Descida rapida — mascaras | *"Usem mascaras, usem mascaras! — Use masks, use masks!"* |
| Situacao controlada (piloto) | *"Tripulacao, situacao controlada"* |
| Aguardem instrucoes (piloto) | *"Atencao, aguardem instrucoes."* |
